Privacy Policy — Hermes Agent

Last updated: 5 October 2026

This Privacy Policy describes how Hermes Agent ("the application") accesses, uses, stores and shares information from Google services. Hermes Agent is a single-user personal automation assistant that runs on the computer of its owner, and it is used only by that owner with that owner's own Google Account. There are no other users.

1. Google data the application accesses

When the owner authorises the application through Google's OAuth consent screen, the application may access the following, strictly for the owner's own account:

  • gmail.readonly, gmail.send, gmail.compose, gmail.modify — to read the owner's mail, to prepare replies on the owner's request, and to send those replies.
  • calendar — to read the owner's agenda and to create or update the owner's appointments.
  • drive — to store and retrieve the owner's documents and files.
  • documents and spreadsheets — to create and edit the owner's documents and spreadsheets.
  • tasks — to record and update the owner's tasks and reminders.
  • contacts.readonly — to recognise the correspondent's name when preparing a message.

2. How the data is used

The data is used exclusively to carry out the tasks the owner asks for: summarising and answering the owner's own email, maintaining the owner's own calendar and task list, and producing the owner's own documents. The application does not use Google data for advertising, does not build profiles, does not score or evaluate people, does not make automated decisions about third parties, and never acts without the owner's instruction.

3. Storage and retention

All data is processed and stored locally, on the owner's own computer. The application keeps a local record of the tasks it performed so the owner can review them. Stored data is retained until the owner deletes it or revokes the application's access, and credentials are stored locally in the owner's user account on that computer.

4. Sharing with third parties

Google user data is never sold, rented, traded, published or transferred to any third party. It is not shared with advertisers, data brokers or any other external service, and no human other than the owner has access to it.

5. Limited Use

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Security

Access to Google services is granted through OAuth 2.0. The application stores only the OAuth credentials it needs, on the owner's own computer, and the owner may revoke access at any moment.

7. Revoking access and deleting data

The owner can revoke the application's access at any time at myaccount.google.com/permissions. Revoking access stops all further processing. To have the locally stored copies deleted, the owner simply deletes the application's data folder on that computer.

8. Changes

Any change to this policy will be published on this page, with the date updated above.
